# Agent Context

AOS-Jarvis is a local-first, secure Agentic System Control Plane. Long-term it should feel like a Jarvis-like assistant; short-term the MVP is a CLI-first, Linux-first, auditable filesystem and command assistant.

Read `PHASE_CONTRACT.md`, `TASK_BOARD.md`, `SECURITY_BOUNDARIES.md`, `TOOL_CAPABILITIES.md`, and `CODING_RULES.md` before doing any work. See `ROADMAP.md` for the full phase plan and `ARCHITECTURE.md` for the target data flow.
