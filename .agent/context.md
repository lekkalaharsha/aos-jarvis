# Agent Context

AOS-Jarvis is a local-first, secure Agentic System Control Plane. Long-term it should feel like a Jarvis-like assistant; short-term the MVP is a CLI-first, Linux-first, auditable filesystem and command assistant. Full scope: `PROJECT_SCOPE.md`. Architecture: `ARCHITECTURE.md`. Security: `SECURITY.md`.

## Non-negotiable rule

Models are providers, not executors (`MODEL_PROVIDER.md`). Every risky action is permission-gated, previewed, audited, and rollback-aware where possible.

## Before doing any work

Read `AGENTS.md`, `PROJECT_STATE.md`, `TASKS.md`, `HANDOFF.md`, `BLOCKERS.md`, `ARCHITECTURE.md`, `SECURITY.md`, `DEVELOPMENT_WORKFLOW.md`. See `.agent/current_context.md` for the shorter day-to-day pointer version of this file and `.agent/current_goal.md` for what's active right now.
